## 一句话介绍
i Ghostty Config 是一个基于 Web 的 [Ghostty](https://ghostty.org/) 配置编辑器：可视化调整设置、实时预览、一键配置。

## 快速开始

```bash
git clone https://github.com/HaoRangQi/iGhosttyConfig.git
cd iGhosttyConfig
bun install
bun run dev
```
启动后访问 `http://localhost:5173`。

## 运行模式

- 本机直连（读取/写回本机配置）：见 [Local Companion 文档](./docs/guides/local-companion.md)。
- Docker使用（Docker + 浏览器文件授权）：见 [Remote Team Mode 文档](./docs/guides/remote-team-mode.md)。
